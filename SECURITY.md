# Security Policy

## Supported versions
| Version | Supported |
| --- | --- |
| latest release | yes |
| older | no |

## Reporting a vulnerability
Report privately through GitHub: Security tab, "Report a vulnerability" (private vulnerability reporting is enabled). Do not open public issues for vulnerabilities.
This is a one-maintainer project, so we aim to acknowledge reports within 7 days.

## Secure development expectations
- No credentials, tokens or confidential incident data in the repository, issues or this file.
- Dependencies reviewed on change and monitored for vulnerabilities; secret scanning in CI.
- Threat model kept current: [docs/security/threat-model.md](docs/security/threat-model.md).

## Disclosure
Fixes are released first; details are disclosed after a fix is available, coordinated with the reporter.
