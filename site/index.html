migadu-cli

An unofficial command line for Migadu: domains, mailboxes, aliases, identities, forwardings and rewrites from the terminal. API keys come from your password manager.

Download a ready-made binary for macOS, Linux or Windows from the latest release, or build it with Rust:

cargo install --git https://github.com/ifthenelse/migadu-cli
migadu mailboxes list -d example.org
export MIGADU_EMAIL=you@example.org
export MIGADU_API_KEY_REF="op://Private/Migadu/credential"
migadu tier
migadu mailboxes create -d example.org -f local_part=alice -f name=Alice -f password=<secret>

Works with 1Password, Bitwarden, pass, KeePassXC, macOS Keychain and Linux Secret Service.

How do I create a Migadu mailbox from the command line?

Export MIGADU_EMAIL and MIGADU_API_KEY (or MIGADU_API_KEY_REF), then run migadu mailboxes create -d example.org -f local_part=alice -f name=Alice -f password=<secret>. Migadu's API needs a plan that includes it (not Micro).

Where does the API key live?

In your password manager. op://, bw:, pass:, keepassxc: and keychain: references are resolved by running that tool without a shell. Nothing is stored.

Does it work on my system?

There is one native binary for macOS (Arm and Intel), Linux (x64 and Arm) and Windows, with checksums on each release.

What can it not do?

Domain aliases are not implemented. Plan, catchall, spam and Bcc settings use your admin-panel session cookie and may break when Migadu changes the page. It is unofficial and not affiliated with Migadu.

How is it different from the Terraform provider, the MCP server or migaman?

Terraform declares state, the MCP server is for AI assistants, and migaman manages aliases only. This is a terminal tool for the other mailbox, forwarding, rewrite and domain tasks.
